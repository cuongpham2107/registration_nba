# Plan: Tối ưu hiệu năng trạng thái bảng Registration

## Nguyên nhân chậm

Model `Registration` **không cast** `start_date`/`end_date` thành Carbon → mỗi lần dùng phải `Carbon::parse()` lại từ string. Mỗi dòng trong bảng gọi `Carbon::parse()` **8 lần**:
- `recordClasses`: 2 lần
- `color()`: 2 lần
- `formatStateUsing()`: 2 lần
- `QuickReregisterAction::hidden()`: 2 lần

Với 25 dòng/trang = **200 `Carbon::parse()` mỗi lần load trang** — gây chậm rõ rệt.

## Cách sửa

### 1. Thêm `$casts` vào model Registration
**File:** `app/Models/Registration.php`

Thêm:
```php
protected function casts(): array
{
    return [
        'start_date' => 'datetime',
        'end_date' => 'datetime',
        'approved_at' => 'datetime',
    ];
}
```

Dùng `casts()` method (Laravel 12 style) thay vì `$casts` property.

Sau khi cast, `$record->end_date` và `$record->start_date` là Carbon instance → gọi `.isPast()`, `.diffInDays()` trực tiếp, không cần `Carbon::parse()`.

### 2. Bỏ `Carbon::parse()` trong tất cả closures
**File:** `app/Filament/Resources/Registrations/Tables/RegistrationsTable.php`

Thay `Carbon::parse($record->end_date)->isPast()` → `$record->end_date->isPast()`
Thay `Carbon::parse($record->start_date)->diffInDays(Carbon::parse($record->end_date))` → `$record->start_date->diffInDays($record->end_date)`

ở 3 vị trí: `recordClasses`, `color()`, `formatStateUsing()`.

### 3. Bỏ `Carbon::parse()` trong QuickReregisterAction
**File:** `app/Filament/Resources/Registrations/Actions/QuickReregisterAction.php`

Tương tự, bỏ `Carbon::parse()` trong `hidden()` closure.
